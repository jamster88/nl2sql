# Index Descriptions

## DDL Index

* Contains creation statements for all the tables in scope along with description of table/columns as comments.
* This will provide table & column definitions to LLM

## Business Index

* Holds business-related terminologies and documentation to aid the LLM in generating contextually accurate SQL queries.
* This index also contains any documentation in context to the database, tables and columns which will help LLM to generate correct SQLs. For example, join with master_data table to understand any code-decode values.
